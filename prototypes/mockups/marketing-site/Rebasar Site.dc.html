Powerful Git, no surprises.

Before anything that can lose work runs, Rebasar tells you exactly what's about to vanish. Force-push always uses --force-with-lease. And because Rebasar runs your own git, your hooks, signing and credential helpers behave the way they do in your terminal.

  • ✓--force-with-lease, always
  • ✓Your hooks, your signing, your config

Download

Every release lists a SHA256SUMS file to check your download against.

git

Rebasar needs a system git 2.35.0 or newer, and shows a setup screen when it is missing or older. (Ubuntu 22.04 ships 2.34; install a newer one from the Git PPA.)

Windows

The Windows installer is not code-signed yet, so SmartScreen may show "Windows protected your PC". Choose More info, then Run anyway.

Linux

Linux doesn't store credentials yet: to use GitHub pull requests there, sign in with the GitHub CLI (gh auth login).
